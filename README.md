# Sistema Backend de Turnos y Reservas - Primera Pre-entrega

## Descripción del Proyecto
Este proyecto corresponde a la primera pre-entrega del curso de Programación Backend I en Coderhouse. Consiste en la implementación de una aplicación en Node.js utilizando módulos ESM (`import`/`export`), un sistema de configuración segura de variables de entorno con `dotenv`, y una clase administradora (`ServiceManager`) para gestionar servicios mediante persistencia en archivos JSON (`FileSystem`).

## Tecnologías Utilizadas
* Node.js (v24+)
* Express.js
* Módulos ESM
* Dotenv (gestión de variables de entorno)
* FileSystem (`fs/promises`)
